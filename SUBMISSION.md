## Application
GradeLedger is a C# student grade manager with a Windows Forms dashboard and a console menu. It supports adding, displaying and searching students, average/highest/lowest calculations, validation and exception handling. Additional features include grade updates, confirmed removal, JSON saving and CSV export.

## Technical implementation
The shared core uses `Dictionary<string, int>`, functions, conditionals, loops, LINQ `Average/Max/Min`, a grade-category enum and record structs. Both interfaces call the same core operations.
